PUBLICAÇÃO — ORDEM ÚNICA
========================

1) SUPABASE > SQL Editor
Execute somente supabase/JUNIOR_SQL_UNICO_OFICIAL.sql.

2) SUPABASE > Edge Functions
Crie/republique exatamente:
- junior-infinitepay-gateway -> supabase/functions/junior-infinitepay-gateway/index.ts
- junior-admin-media -> supabase/functions/junior-admin-media/index.ts
Verify JWT: DESLIGADO nas duas.

Secrets / variáveis:
- SUPABASE_URL: padrão do Supabase
- SUPABASE_SERVICE_ROLE_KEY: padrão do Supabase, somente dentro das Edge Functions
- JUNIOR_INFINITEPAY_HANDLE: opcional; se ausente, o código usa antonio-junior-zzc
- JUNIOR_PERSONAL_PIX_KEY: obrigatório apenas se for usar Pix pessoal
- JUNIOR_PERSONAL_PIX_OWNER: obrigatório apenas se for usar Pix pessoal

3) GITHUB
Publique todos os arquivos da pasta final no repositório da rifa.
Depois abra o Admin e pressione Ctrl+F5 uma vez.

- Na página pública, reserve UM número livre em Dinheiro, informe comprador/recebedor, confirme que aparece como pendente no Admin e depois libere o número de teste pelo Admin.
